# Update the AI log

1. Read `docs/AI_LOG.md` and identify the current milestone section.
2. Record only tools, prompts, tasks, and outcomes that actually occurred.
3. Describe what the assistant generated and what I reviewed, kept, changed, or rejected.
4. Record a mistake only when it was observed, how it was noticed, and how it was fixed.
5. Never invent a tool, prompt, student action, or mistake. Ask me when a fact is uncertain.
6. Do not add AI references or comments to source code.
